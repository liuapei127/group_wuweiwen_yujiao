# 37 ENT 权限修复执行说明

日期：2026-11-11

## 本轮完成

本轮直接修改本地代码，优先修复日报、请假、口语查库与指令入口的权限缺口。未部署到腾讯云。

| 功能 | 本轮行为 |
| --- | --- |
| 日报提交 | 请求 employee_id 必须等于可信员工身份，否则 HTTP 403，不更新他人日报 |
| 日报查询 | 默认只查本人；指定其他员工返回 403；日期范围倒置返回 422 |
| 请假列表 | 只返回明确分配给当前员工的待审批请假；未分配单据不向普通员工开放 |
| 请假审批 | 必须是指定审批人；更新语句再次核对单号、类型、pending 状态与审批人；失效更新返回 409 |
| 按名审批 | 同名学生或当前审批范围内存在多张待审批单，返回 409，要求按单号操作；decision 必须明确给出 |
| 客户按名查询和指令 | 先限制当前员工名下，再匹配姓名；同名多条返回 409，不擅选第一条 |
| 口语查库 | 五类查询全部绑定员工范围；拒绝外部覆盖范围、额外参数和 SQL；参数错误返回 422 |
| 错误响应 | 请假、commands、NL2SQL 使用真实 HTTP 4xx，同时保留 code/message/data 格式 |

## 当前采用的最小权限边界

日报只支持本人，不把员工登录等同主管权限。主管跨员工/部门访问仍需 BASE 的角色和数据范围契约。

请假暂以 student_admin_service.approver_id 的明确分配作为范围。STU/BASE 必须通过可信服务端规则分配审批人，不能允许学生随意指定。字段为空的单据暂不可审批，不能改成所有员工可领取。若团队另定班级、部门或角色规则，需要再接入服务端授权策略。

生产 require_employee 仍默认 503，trusted_jwt 仍未实现。本次测试通过依赖覆盖模拟员工身份，只用于验证应用授权行为，不代表登录验收通过。
