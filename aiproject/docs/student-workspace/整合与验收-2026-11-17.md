## 已接入功能

| 功能 | 行为与数据来源 |
| --- | --- |
| 学生欢迎首页 | 展示本人申请、近期考务与通知；可进入请假、助手和生活指南 |
| 我的学籍 | 只读显示学籍姓名、学号、项目、当前班级、班主任、院校和专业；使用现有入班记录 |
| 通知详情 | 显示关联请假、反馈或考务的具体内容及处理结果；只查询本人有权查看的来源 |
| 助手分步办理 | 收集假别、时间、原因或反馈分类及内容；形成持久草稿，核对后确认提交 |
| 暂停与恢复 | 会话切换或中途查询保留草稿；刷新后恢复，过期后要求重新核对 |
| 防重复与一致性 | 校验归属、状态及版本；业务记录、员工待办、回执同事务保存，重复确认回放原结果 |
| 德国、新加坡生活指南 | 各6类、共12篇指南及36条FAQ；支持地区切换、搜索、阅读步骤、来源与核对日期 |
| Dify知识检索 | 两国独立外部知识库，配套18节点工作流；模型理解诉求，后端查询事实与执行确认 |
| 降级 | Dify故障时保留本地分步办理和已导入公开知识，已有草稿仍可确认或取消 |

另外修正了生活资料仅检索前50篇的限制：网站搜索和助手查询按批次读取后续资料，避免较大资料库漏查。社交回复中无依据的代为联系承诺会被拒绝。

## 当前业务保留情况

没有删除现有业务模块。保留项目多班级、每班一名班主任、管理员入班与转班、未完成事项交接、老师停用前交接、三阶段课程和成绩、整班考务、请假可选证明及老师查看、投诉纠错重新分派。

游客预约缺姓名时补填、登录联系方式默认值、游客昵称、游客材料查看与识别导入、客户研判、员工日报与周报、企业助手和自评关怀继续使用当前实现。课程不收费、项目费用签约时处理的规则保持原实现。游客首页未恢复已移除的“我的资料”顶栏按钮。

原有近期考务自动刷新提示保留；欢迎首页展示近期事项，助手采用独立对话布局，其余学生业务页继续显示考务提示。

## 内容范围

生活资料使用输入包中的公开来源与核对日期；本轮另外检查了紧急求助、医疗保险及新加坡入境官方入口。紧急号码对应出处为 [德国官方生活指南](https://www.make-it-in-germany.com/en/arriving-living/getting-started/everyday-knowledge)、[新加坡警方](https://www.police.gov.sg/Contact-Us)、[新加坡民防部队](https://www.scdf.gov.sg/home/about-scdf/emergency-medical-services)。

当前公开问答按关键词及问题片段排序，不是实时全网检索。没有实时定位、地图、天气或自动联系外部机构的能力。院校和教学事实以现有员工登记记录为准；未登记信息不会由聊天记忆补成已核实资料。
