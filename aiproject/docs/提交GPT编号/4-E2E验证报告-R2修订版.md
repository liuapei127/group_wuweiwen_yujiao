## 1. 相对 R1 的重要修正

| 项目 | R1（作废） | R2（当前） |
| --- | --- | --- |
| 鉴权表述 | 「未绕过鉴权」 | **不正确**。当时可无 `X-Employee-Id` 改状态 |
| 认证实现 | 无 | `require_employee`：Bearer + `AUTH_BEARER_TOKEN` + `X-Employee-Id` |
| 未配置 token | 业务可访问 | **503** 业务不可用 |
| 无 Bearer | 部分可操作 | **401** |
| 权限失败 | HTTP 200 + code=403 | **HTTP 403** |
| 状态冲突 | HTTP 200 + code=400 | **HTTP 409** |

**准确表述**：

> 当前接口尚未实施**公共员工登录认证**。R1 仅验证在弱约束下的业务读写。R2 起默认拒绝未认证请求；`AUTH_BEARER_TOKEN` 为本地/服务间过渡方案，**不等于**生产可信身份。
