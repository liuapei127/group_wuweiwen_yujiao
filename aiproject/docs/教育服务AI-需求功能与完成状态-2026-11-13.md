### 32 节点企业助手

旧版 4 个业务 HTTP 节点直接调用旧 8000 入口，节点缺员工 Authorization 凭据，无法通过现有受保护业务接口。旧版还由 Dify 保存待确认动作，与工作台后台持有的确认状态重复。

本机发布版保留 32 个节点。健康检查改为当前 8003 后端，原四个业务 HTTP 节点改为返回结构化指令。Dify 只接收指令文本和必要的对话上下文，员工令牌、权限和写入确认由工作台后端处理。实测普通员工查待办、取消、确认写入一次和重复确认拦截均通过。独立 Dify WebApp 已关闭，员工从工作台使用。

## 7. 后端 API 数量与清单
