## C. 身份与安全（GPT §5）

| 项 | 现状 | 缺口 |
| --- | --- | --- |
| 登录与会话 | 无 `modules/auth` | 与公共认证负责人定 Token / 会话 |
| Dify → API 身份 | 可选头 `X-Employee-Id` | **可伪造**；审批与客户状态不能据此验收 |
| Dify 失败分支 | 未配置 | HTTP 非 200 或 `code≠0` 时禁止回复「已成功」 |
| NL2SQL | 白名单 intent，拒 `sql`/`raw_sql` | 需与员工数据范围绑定（经理/顾问） |
